# Git-Concepts-Commands

🔹 Git Basics & Core Concepts

--> Concept	Explanation

Q. Commit	

A. snapshot of your project at a given point in time. Immutable and identified by SHA-1 hash.


Q.Branch	

A. lightweight pointer to a commit. main or feature/login are examples.


Q.HEAD
	
A. reference to the current branch and the latest commit you're on.


Q. .git Directory	

A. Stores all Git metadata: commits, branches, logs, config, objects, etc.
