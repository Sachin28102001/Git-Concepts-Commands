🔹 Staging Area, Working Dir & .git Dir

Area	       -         Explanation
Working Directory	-    Actual files you edit.
Staging Area (Index) -	Temporary area to prepare what goes in the next commit.
.git Directory	-        All the history, metadata, and internal structure.

👉 Flow:
You edit → git add → goes to staging → git commit → saved to .git database.
